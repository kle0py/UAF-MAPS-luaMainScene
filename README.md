# UAF-MAPS-luaMainScene
MainScene maker for MAPS in LUA format on the UbiArt Framework (for Just Dance).

UPDATE (09/30/2026)
- Added support for up to 6 players.
- Autodance files are now generated correctly (with no in-game errors)
- Added the Dash MPD ".hd.vp9" file in VideosCoach.

**⚠️: The generation of ‘.mpd’ files are placeholders!**
